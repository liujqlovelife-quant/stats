# 笔记编辑规范

- 包含数学公式的 Markdown 笔记必须以 GitHub 实际渲染结果为交付标准，不能只检查源文件或公式分隔符配对。
- 块公式优先使用 `math` 围栏代码块，避免公式内部独占一行的等号被 Markdown 识别为 Setext 标题。
- 行内公式优先使用 GitHub 支持的美元符号包裹反引号语法（例如 $`E[Y\mid X]`$），避免相邻中文标点导致解析失败。
- 当前目标页面拒绝过 `\operatorname`；普通直立名称可使用 `\mathrm{Var}`、`\mathrm{Cov}` 等兼容写法，保持数学含义不变。
- 提交后打开或刷新 GitHub 预览，核对块公式和行内公式的渲染数量，检查未解析的美元符号、LaTeX 原文和渲染报错，并抽查复杂公式与表格。
- 如无法完成实际渲染验证，应明确说明未验证，不能仅凭源码正确宣称公式显示正常。
